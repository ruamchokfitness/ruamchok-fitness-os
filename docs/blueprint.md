# **App Name**: FitFlow HR

## Core Features:

- Employee Management: Add, view, and update employee names within the system.
- Leave Tracking: Record various types of employee leave, including vacation, public holidays, and custom leaves.
- Leave Quota Configuration: Administrators can set and assign individual quotas for different leave types (e.g., vacation days, holiday allowances) to each employee.
- Dynamic Holiday Entitlements: Manage employee-specific permissions for standard public holidays and allow for the creation and allocation of custom additional holidays.
- Policy and Settings Management: Allow administrators to view and inline-edit general leave policies, such as vacation accrual rules and holiday restrictions.
- Real-time Leave Balance Display: Automatically calculate and prominently display each employee's remaining leave days for all categories, providing a clear and up-to-date overview.

## Style Guidelines:

- Primary color: A clean, vibrant Royal Blue (#1A73E8) to convey trustworthiness and energy, used for key actions and branding. HSL(220, 80%, 55%).
- Background color: A very light, subtly cool gray-blue (#F6F8FC) providing a neutral and expansive canvas that supports readability. HSL(220, 15%, 97%).
- Accent color: A refreshing and active green (#2EB34A) for success messages, additions, and highlighting positive states, offering strong visual contrast. HSL(120, 60%, 45%).
- Body and headline font: 'Sarabun', a sans-serif font, for both headlines and body text, ensuring clear readability and a professional appearance, especially for Thai script. Note: currently only Google Fonts are supported.
- Utilize simple, modern outline icons for all functional elements and navigation, such as the Lucide icons referenced in the existing codebase, to maintain a clean and lightweight aesthetic.
- Implement a clean and modular layout, with employee cards arranged in a responsive grid. Essential policy and configuration details are clearly segregated for easy management across various screen sizes.
- Incorporate subtle hover effects and transition animations on interactive elements, such as buttons, form fields, and employee cards, to enhance user experience and provide smooth visual feedback.
